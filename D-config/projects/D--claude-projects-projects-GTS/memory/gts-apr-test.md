## 新手引导漏斗

按天观察 0428-0501 新手流程漏斗，**「启动分镜结束 → 击败怪物」这一步流失率波动极大**：

| 日期 | 流失率 |
|------|--------|
| 0428 | 8.20% |
| 0429 | 3.31% |
| 0430 | 0.59% |
| 0501 | 2.81% |

- 4天内同一步骤流失率从 8.2% 降到 0.59% 又反弹到 2.81%
- 说明不是设计问题，而是技术/版本/服务器等外部因素
- 此波动直接干扰次留判断和买量优化决策

## 产品体验反馈

体验时长 2-4 小时后可玩性和趣味性骤减：
1. 单机任务重复单一
2. 任务点之间路径过长
3. 路线单一无探索乐趣
4. 2-4小时后内容断崖

## 核心结论

1. **买量成本极低**：Install CPI $1.58，远优于行业 $3.5-$5
2. **次留 27.56% 比2月提升 8pp**，但离行业正式发行标准 36.3% 仍有差距
3. **留存衰减 55.47% 是最大瓶颈**（行业 ~41%），第二日内容急需优化
4. **模拟经营是唯一摸到行业线的方向**：AEO 次留 36.44%
5. **浴血黑帮 CPI $1.14 最低 + 次留 30.23%**，但量级小，需扩量验证
6. **超速被抓、战斗形式淘汰**：货不对板或录屏接不住点击
