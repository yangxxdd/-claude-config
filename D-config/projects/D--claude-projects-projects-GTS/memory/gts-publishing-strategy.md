# GTS 题材扩展与发行策略

## 一、核心问题

黑帮 SLG 是一个真实但小众的细分市场。**友塔（Yotta Games）以 Mafia City + The Grand Mafia 两款产品垄断该品类。**

GTS 如果只做"更好的黑帮SLG"：
- 天花板 = Grand Mafia 累计收入约 $3.74 亿（第三方估算）
- IGG Mafia Mobile（2025.9）首月全球收入约 97 万 RMB → 纯跟风死路一条

**结论：GTS 必须以黑帮为底色，向外融合一个大题材。SLG 过去三年最大赢家的公式：大题材前端破圈 + SLG 后端变现。**

## 二、扩展方向评估

| 方向 | 验证竞品数 | 竞品总规模 | 空白 | 推荐 |
|------|-----------|-----------|------|------|
| **丧尸+黑帮** | 5款 | $50-70亿/年 | 0款犯罪视角 | **P0** |
| **废土+黑帮** | 5款 | <$1亿（无大SLG） | 0款帮派SLG | **P0** |
| **海洋+黑帮** | 4款海盗 | Sea of Conquest 1亿注册 | 0款现代走私 | **P1** |
| **监狱+黑帮** | 2款+ | Lands of Jail 月峰值9000万 | 0款囚犯视角 | P2 |

### 方向1：丧尸末日 + 黑帮 🔥🔥🔥

**竞品 5 款，合计年收入 $50-70 亿，全部"幸存者视角"。**

- State of Survival（FunPlus）：累计 $14 亿
- Last War: Survival（元趣/Funfly）：累计 $26 亿+
- Doomsday: Last Survivors（IGG）：月峰值 ~$16.7M
- Age of Origins（壳木）：累计 $10 亿+
- Puzzles & Survival（三七）：累计超 150 亿 RMB

**GTS 切入**：末日=权力真空=黑帮的黄金时代。你不是躲丧尸，你是**利用末日建帝国**。

**素材钩子**：安全区=保护费、西装暴徒打丧尸、丧尸工厂（铁链拴丧尸干活）

### 方向2：废土沙漠 + 黑帮 🔥🔥🔥

**竞品 5 款，0 款做帮派 SLG。Mad Max 文化基础扎实，无 SLG 转化。**

- Mad Survivor: Arid Warfire（LeyiGames）：沙漠废土 SLG
- Ashworld（OrangePixel）：像素废土，Mad Max 致敬
- 锈蚀与愤怒（Puzzle Point）：废土塔防
- 漠土之息（神匠互娱）：沙漠废土 RPG
- Last Oasis Survivor：沙漠水稀缺生存策略

**GTS 切入**：Mad Max + 教父。水=新货币，油田=新地盘。

**素材钩子**：最后一桶水、沙暴奇袭、改装车追逐战

### 方向3：现代海洋 + 黑帮 🔥🔥

**竞品 4 款海盗 SLG，全是 18 世纪帆船奇幻。0 款现代。**

- Sea of Conquest（FunPlus）：1 亿注册
- Pirates of the Caribbean: ToW（JOYCITY）
- Stormshot（FunPlus）
- Lord of Seas（SPARKLER）

**GTS 切入**：Narcos meets Sea of Conquest。快艇、毒品潜艇、走私航线。

**素材钩子**：黑夜快艇、毒品潜艇浮出、海岛豪宅+快艇

### 方向4：监狱 + 黑帮 🔥

**Lands of Jail 月峰值 9000 万 RMB，验证了"非传统战争题材+经营+SLG"在海外可行。**

**GTS 切入**：Lands of Jail 是典狱长视角。GTS 做**囚犯视角**——从入狱→监狱帮派头目→出狱建帝国。

## 三、落地路径

1. **素材验证（2-4周）**：P0 两个方向各 3 条低成本 AI 素材，跑 300-500 install，数据定方向
2. **概念美术+立项（1-2月）**：概念图 + 用户画像 + 商业化模型
3. **最小版本验证（2-3月）**：7 日内容，KPI 参考 R1≥25%，R3≥15%

## 四、发行运作模式：破圈 → 长留 → 变现

> GTS 不是传统 SLG，而是"黑帮经营 + 角色养成 + 轻 SLG 社交"的复合模型。
> 三段式并非绝对分离——破圈素材吸引进来的人，必须在产品前 3 天完成"经营承接"。

### 1. 破圈：黑帮题材拉新

**目标**：CPI 控制在 $1.6-$2.0（install）/ $2.0-$3.0（aeo）

| 钩子类型 | 素材方向 | 已验证数据 | 目标人群 | 制作方式 |
|---------|---------|-----------|---------|---------|
| 氛围/世界观 | 浴血黑帮复古→街头火并→赛博都市 | CPI $1.14 + 次留 30.23% | 核心商业化用户（美加英澳） | AI→UE→AE |
| 身份/权力 | 小人物逆袭→黑道教父、跟谁混 | CPI $1.56-1.82 | 权力欲/复仇爽群体 | UE+AE |
| 反差/猎奇 | 黑帮大哥做炸鸡/披萨 | CPI $1.37 最低 + 次留 30.77% | 泛用户/猎奇 | AI |
| 爽感/战斗 | AOE清屏/帮派火并 | CPI $1.59 + aeo 次留 30.36% | 暗黑/RPG用户 | UE+AE |

### 2. 长留：经营+养成双线驱动

**目标**：D1 次留 ≥35%（当前 27.56%），D3/D1 衰减 ≤45%（当前 55.47%）

#### 经营线（留存底盘）

```
用户进入 → 接任小地盘 → 建设产业(赌场/夜总会/酒吧)
→ 收益增长 → 扩张地盘 → 解锁新产业类型
```

| 节点 | 内容 | 留存作用 |
|------|------|----------|
| D1 | 接任初始地盘 | D1 次留 |
| D2-D3 | 建设第一个产业 | D3 次留（核心痛点） |
| D4-D7 | 解锁第二/三种产业，小弟系统 | D7 次留 |
| D8-D14 | 产业升级/分支，羁绊系统 | D14 次留 |
| D15-D30 | 跨产业协同+家族经营 | D30 留存 |

#### 养成线（留存粘性）

```
角色收集 → 培养升级 → 羁绊组合 → 外观/称号 → 稀有度追求
```

| 节点 | 内容 | 留存作用 |
|------|------|----------|
| D1-D3 | 获得首批小弟/契约者 | 新鲜感 |
| D4-D7 | 首张 SSR/稀有角色 | 收集欲 |
| D8-D14 | 羁绊组合、外观自定义 | 个性化 |
| D15-D30 | 限定角色/皮肤、赛季稀有度 | 稀缺性 |

### 3. 变现：轻 SLG 社交+赛季竞争

**目标**：D7-D30 逐步引入社交竞争，通过家族荣誉/排行榜/赛季结算驱动付费。

#### 三级付费阶梯

| 层级 | 付费点 | 时机 | 逻辑 |
|------|--------|------|------|
| 轻量 $0.99-$9.99 | 首充礼包（SSR小弟） | D1 | 低门槛 |
| | 月卡/经营加速 | D3-D5 | 省时间 |
| | 限定皮肤/外观 | D5-D7 | 炫耀驱动 |
| 中度 $10-$50 | 赛季通行证 | D7-D14 | 性价比锚定 |
| | SSR限定池 | 活动周期 | 收集欲 |
| | 产业加速包 | D7-D14 | 突破瓶颈 |
| 重度 $50+ | 家族战/GVG消耗 | D14-D30 | SLG 最大付费驱动力 |
| | 排行榜争夺 | 赛季中 | 荣誉感 |
| | 限定称号/跨服荣誉 | 跨服活动 | 炫耀 |

## 五、GTS vs 吸血鬼（孟帅版）

| 维度 | 吸血鬼 | GTS |
|------|--------|-----|
| 破圈钩子 | 吸血鬼题材+血液/怪物猎奇 | 黑帮权力/复仇+反差幽默+氛围混剪 |
| 长留底盘 | 永夜街经营+契约者关系 | 地盘经营+小弟养成+羁绊系统 |
| 变现引擎 | 血族宴会冲榜+家族排行+GVG | 家族战/GVG+赛季排行+限定角色 |
| 回收模型 | 欧美 8-10 个月 | CPI 目标 $1.6-$1.8（美国） |

## 六、一句话总结

**纯黑帮 SLG 天花板有限。GTS 不做第二个 Mafia City。Lands of Jail 用监狱+SLG 做到月 9000 万——GTS 用一个更大的舞台做同样的事。**
