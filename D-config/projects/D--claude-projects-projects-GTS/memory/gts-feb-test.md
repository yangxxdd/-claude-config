### 关键结论

1. **美国买量单价 $1.89，显著优于美国 SLG 策略品类 $3.5-$5**
2. **菲律宾 $0.21，与菲律宾 SLG 品类 $0.2 持平**
3. **素材特点**：警匪互动/大尺度剧情开头、简单直观的数值展示（金额、战力）在美国吸量更好
4. **模拟经营在菲律宾表现最优**，最低单价 $0.13
5. **视频素材美国 CTR 4%-7%**，素材对美国核心用户吸引力足够
6. **战斗录屏效果差**：V-战斗形式 CTR 最高但 CVR 最低，录屏接不住点击
