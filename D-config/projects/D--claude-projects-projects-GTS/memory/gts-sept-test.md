## 9月目标线（优秀 / 合格 / 待改进）

**留存（Install）**：D1 30% / 25-30% / 20-25% · D3 16% / 12-16% / 8-12% · D7 10% / 7-10% / 4-7%（首次验证）· CPI ≤$2.0 / $2.0-3.0 / >$3.0

**AEO 上浮**：D1 35/30-35/25-30 · D3 18/14-18/10-14 · D7 12/9-12/6-9

**付费（仅 3 指标）**：CPI(AEO付费) ≤$20 / $20-25 / >$25 · 首日付费率 ≥5% / 3-5% / <3%（Lordrush 3.5% 依据）· 首日 ROI ≥10% / 5-10% / <5%（SLG 首日回收低）

> 目标线逻辑：优秀=行业衰减线（D30=4% 锚，逐级 D1→D3≈58%→D7≈60%→D14≈60%→D30≈65%），合格=往上提，待改进=贴近实测。GTS 7月 D3 实测 4.08% 远低于任何线，D3 是硬伤。

## 分组（8组，不跨格式）

方案A 纯留存 = 视频 Camp 4 组 + 图片 Camp 4 组（各 CBO，拆 2 个 Camp 避免视频抢图片量）
- 视频：黑帮入会/氛围、角色招募、复仇逆袭(V-晋级失败+V-无厘头擦边)、战斗
- 图片：角色展示、美漫分镜、幽默经营、擦边/命运反转(P-黑帮擦边+P-美漫角色升级)

方案B 付费版 = 6 方向组（预算紧，视频图片混方向组，合并复仇逆袭+美漫、擦边）

## 预算（3:2 直接分配，不预留）

方案A 主导量 $6,750 = 视频 $4,050 + 图片 $2,700（3:2）。差的 Camp 手动减视频加图片。

## 关停规则（锚定目标线 ×1.25）

- Install：花费>$50 且激活=0 → 关；CPI>$3.75（$3.0×1.25）且量级≥15 → 关；CPI≤$2.0 多放到量级≥20 再判
- AEO付费：花费>$80 且激活=0 → 关；CPI>$31（$25×1.25）且量级≥10 → 关
- 通用：单日 DNU<20 → 不关，标观察

## 关键用户反馈（影响后续所有测试）

- 7月 ABO 平均分配 → CPI $3.32 翻倍被上级 diss；此后 **强者恒强 CBO**
- 图片不能一刀切不跑 AEO；但主导量里视频图片要**分赛道**（否则图片被视频抢量）
- 付费目标只写必要的（CPI+首日付费率+首日ROI），"写的越多错的越多"
