## 二、制作方式矩阵

### 三种制作方式定义

- **UE**：Unreal Engine 3D 渲染，高品质 CG/写实画面
- **AI**：Midjourney/Stable Diffusion/可灵/Runway 生成式工具
- **AE**：After Effects 2D 动效包装

### 方向 × 制作方式

| 大类 | 细分方向 | 推荐方式 | 依据 |
|------|----------|----------|------|
| 模拟经营 | 产业经营/赌场/夜店 | UE + AE | V-模拟经营 AEO 次留 36.44% 验证 |
| 模拟经营 | 收益管理/资源分配 | AE 为主 | 纯数据可视化 |
| 战斗系统 | 帮派火并/AOE爽感 | UE + AE | V-爽感战斗 CPI $1.59 |
| 战斗系统 | 复仇逆袭叙事 | UE + AE | V-晋级失败被捕稳 |
| 角色养成 | 小弟/卡牌/图鉴 | AI + AE | 批量生成+动效 |
| 角色养成 | 外观自定义/捏脸 | AI 为主 | 风格变体快速测试 |
| 美术风格 | 写实/赛博/复古 | AI → UE | AI测方向，UE复刻精品 |
| 美术风格 | 漫画/Q版/浮世绘 | AI 为主 | 风格化天然适合AI |
| 幽默反差 | 荒诞经营/搞笑道具 | AI 为主 | P-炸鸡店 CPI $1.37 |
| UI/交互 | 榜单/福利/对比 | AE 为主 | 标准化量产 |
| 场景氛围 | 霓虹街头/地下赌场 | UE + AE | UE5 Lumen 渲染优势 |
| 世界观 | 氛围混剪 | AI + UE + AE | 浴血黑帮已跑通 |

### 制作方式策略总览

| 方式 | 覆盖方向 | 成本/周期 | GTS优先级 |
|------|----------|-----------|-----------|
| UE 为主 | 12个 | 高/1周 | 核心素材 10 条 |
| AI 为主 | 14个 | 低/分钟级 | 高频测方向 50+ |
| AE 为主 | 18个 | 中/半天 | 标准化量产 30+ |
| UE+AE | 26个 | 中高 | 主力素材 20+ |
| AI+AE | 16个 | 低/1天 | 快速测试 15+ |
| AI→UE | 8个 | 中/2-4天 | 品牌向 5-8 条 |

### 核心原则

1. **AI测方向，UE做精品**：62%头部SLG热门素材含AI元素
2. **AE永远不嫌多**：数字/榜单/福利类转化稳定、制作快
3. **UE不是万能的**：纯AE/纯AI素材用UE做是浪费或太慢
4. **浴血黑帮全流程已验证**：AI概念→UE渲染→AE混剪，CPI $1.14 + AEO次留 50%
5. **幽默反差是AI独有优势**：可快速裂变"大佬送外卖/开奶茶店/做美甲"
