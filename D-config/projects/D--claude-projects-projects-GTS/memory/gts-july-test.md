### KPI 目标

| 指标 | Install 目标 | AEO 目标 |
|------|--------------|----------|
| D1次留 | ≥25% | ≥30% |
| D3三留 | ≥10% | ≥12% |
| CPI | $1.50-2.80 | $2.00-2.60 |

### 关停规则

| 出价 | 条件 | 动作 |
|------|------|------|
| Install | 花费>$50 且 激活=0 | 关停 |
| Install | CPI>$3.50 达到一定量级 | 关停 |
| AEO | 花费>$80 且 激活=0 | 关停该 AEO Ad Set |
| AEO | CPI>$4.00 达到一定量级 | 关停 |
| AEO | D1次留 < 同素材 Install D1次留 | 关停（AEO 无增益） |

## 日报摘要

### 7月9日（US Day1）

**总结：CPI整体超标但Day1冷启动偏高正常。晋级失败 $1.79 一枝独秀，AEO无一合格。赌场博弈双线关停。CVR下滑明显。**

- **Install**：$843 / 275安装，CPI **$3.07**（超标）
- **AEO**：$907 / 221安装，CPI **$4.10**（严重超标）
- **合计**：$1,750 / 496安装（接近日预算 $1,900）
- BI 安装 437 个，留存数据未回传

**Install Top 3**：① 晋级失败 $1.79/34DNU ② 跟谁混 $2.45/25DNU ③ P-美漫 $2.14/30DNU
**Install Bottom 3**：赌场博弈 $6.81 · 立绘展示 $5.41 · 模拟经营新版 $5.34
**AEO Top 3**：鸡公大侠 $2.87 · 浴血黑帮 $3.10 · 招募表演 $3.67
**AEO Bottom 3**：赌场博弈 $7.03 · 爽感战斗 $6.37 · 模拟经营原版 $5.00

**动作**：赌场博弈 Install+AEO 双线关停；等 BI D1 次留回传。

### 7月10日（US Day2）

**总结：Install CPI $2.95（超标），AEO $3.72（超标但环比降9%）。D1留存两极分化，模拟经营方向崩盘。D3 砍8留7 切 CBO 冲最后一天。**

- **Install**：$672 / 228安装，CPI $2.95
- **AEO**：$596 / 160安装，CPI $3.72
- 两日累计：$3,018 / 884安装，剩余预算 53%

**7/9 BI D1回传**：
- Install 整体 **22.73%**，AEO **23.15%**
- Install Top：鸡公大侠 41.2% · 浴血黑帮 40.9% · 晋级失败 35.7%
- Install Bottom：跟谁混 10.5% · 披萨店 11.5% · 美漫 14.8%
- AEO Top：浴血黑帮/爽感战斗 30.8% · 特殊设备 29.4%
- AEO Bottom：模拟经营原版 10.5% · 立绘展示 11.1%

**异常**：
- 🔴 模拟经营原版双线崩盘：Install D1 25% + CPI 恶化，AEO D1 10.53%（4月 36.44%）
- 🟡 浴血 AEO CPI $5.12（暴涨 65%）
- 🟡 CVR 持续降：Install 19%→14%，AEO 17%→13%

**D3 决策**：Install 留 4 支（浴血黑帮/晋级失败/鸡公大侠/立绘展示），关 10 支；AEO 留 3 支（爽感战斗/浴血黑帮/招募表演），关 6 支。

**总结：CBO首日，浴血/晋级吃到大半预算。Install CPI $3.23，AEO $3.99。7/10 D1回传 Install 21.13%/AEO 24.84% 均低于目标。三日安装 ~1,160 未达 1,500，延期一天，重开模拟经营 AEO 补测。**

## 关键观察

### 与 4 月对比

| 维度 | 4月 | 7月Day1-3 | 变化 |
|------|-----|-----------|------|
| Install CPI | $1.58 | ~$3.07-3.23 | 明显上涨 |
| AEO CPI | $2.30 | ~$3.72-4.10 | 明显上涨 |
| Install D1 | 21.49% | ~21-22% | 持平 |
| AEO D1 | 30.49% | ~23-25% | 下降 |

- 7月 CPM 明显上涨（受暑期流量竞争/美国节假日后影响）
- 模拟经营原版 AEO 从 4月 36.44% 跌到 10.53%，需排查素材版本或商店包变化

### 方向级结论

| 方向 | 7月结论 |
|------|---------|
| V-浴血黑帮 | CBO 下获量能力验证，但 CPI 比 4 月涨；留存信号仍稳 |
| V-晋级失败被捕 | Install 最稳，CPI 两次都在 $1.56-1.79 |
| V-鸡公大侠 | D1 留存偶发高，但 CPI 不稳 |
| V-模拟经营原版 | 4月明星方向本轮崩盘，需重测/排查 |
| P-炸鸡店/披萨店 | 图片 Install 成本低，但 AEO 无效 |
| V-赌场博弈 | 双线关停，方向不可行 |
| V-立绘展示/招募表演 | 新方向样本小，信号混杂 |
