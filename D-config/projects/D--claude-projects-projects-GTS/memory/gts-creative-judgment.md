# GTS 素材判断标准（v3）+ AI生图打分卡

## 核心：两层分工（判断素材用两把尺子）

- **创意层**（值不值得做）→ 《GTS买量素材判断标准-v3.md》
- **执行层**（做得对不对）→ 《AI生图评判打分卡.md》
- 一句话：v3 管「值不值得做」，打分卡管「做得对不对」。质检合格 ≠ 有吸引力。

## 判断标准 v3 骨架

- **本质层三问**：吸量力 + 付费 + 差异化。承诺兑现降级为「留存风险提示」，非否决项。
- **吸量机制**（底层，相对有限，判断核心）：好奇悬念 / 视觉冲击 / 代入想玩 / 情绪好笑 / 欲望 / 上瘾。形态枚举永远补不全，靠机制归位。
- **决策流程 6 步**：定机制 → 吸量自检 → 付费自检 → 差异自检 → 市场对标(广大大热度+top1&top10) → 自家数据。
- **动作**：放量 / 试点 / 迭代 / 砍。

## AI生图打分卡（执行质检，100分）

- 5 维度：描述还原 25（主体/景别/风格/构图/UI/背景/特效）/ 逻辑合理 25 / 画面完整 20 / 技术瑕疵 15 / 场景适配 15（游戏感+冲击力）。
- 参考图阶段：技术瑕疵（乱码/手部）权重下调——美术会重制，不为它一票否决重生成。提示词八要素含 UI游戏感/景别/背景/特效（这四块之前漏了）。
- 硬伤一票否决：黑线硬分割(非漫画语境) / 肢体严重畸形 / 文字乱码 / 主体跑题 / 无关元素凭空堆叠。
- 分档：≥85 可用 / 70-84 修图 / 50-69 重生成 / <50 重写提示词。
- 实战补充规则（详见打分卡文档）：①文字乱码分档——大面积明显→重生成，局部隐约缩略图不可见→修图抹除（重生成有随机性会损失表现力）；②核心需求未达成（角色一致性/跑题/货不对板）→直接重生成不看分数；③提示词文字策略——数字/文字是加分项别一刀切禁掉，要数字明确写"LV.60"，不要文字要点名排除载体（招牌/画/菜单/管道/包装）。

## 关键认知（用户纠正，勿再犯）

- 假副玩法是买量常态：承诺兑现优先级不高，**吸量便宜 + 用户付费**才是投放最看重的。
- 数据是投后裁判，投前判断靠「素材特征」不是「结果指标」。
