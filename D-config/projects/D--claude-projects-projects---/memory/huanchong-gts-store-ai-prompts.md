## 重要写作教训
1. **"单场景叙事"非万能药**：仅适用于"结果贴片/空间脱节"型方向（如05-B）。03方向本质是游戏内界面截图，制作人明确要"角色+锁定/解锁状态+UI"，应保持界面式写法。
2. **提示词正文不含 `|`**：用户复制时需手动去`|`，已在生成文件中去掉；飞书表备注列仍用`|`作内部分隔（不改）。
3. **孤立手指突兀**：避免"手指拖钱"作主体，用"角色手势引导"替代，且手势非主角。
4. 每方向需对照「PDF构图」（制作人意图）+「研发参考」（游戏内真实画面）双图。
