# 素材脚本编写 SOP

**适用范围：** 所有项目（幻宠、GTS、日常等）的广告素材脚本。
**目标交付物：** 飞书在线表格里的「美术工单」——打开即懂、只留执行信息。

---

## Step 0: 资产盘点
确认可用角色/场景/UI/音效。
**红线：不虚构游戏里不存在的机制。** 不确定就问用户或查配置。

## Step 1: 找参考（强制）
只找竞品广告和跨品类参考视频，不找同类游戏截图。
参考必须具体到文件名或链接。

## Step 2: 创意提案
出 2-3 方向，每个一句话钩子 + 反转逻辑 + CTA。
**不等用户确认不往下走。**

## Step 3: 按顺序出内容

### 3a（先做）写「概述」
- 中文一句话梗概
- 8-10 行剧情线
- 目标：美术 30 秒理解全片

### 3b（再做）拆分镜
- 目标 ≤5 镜
- 每镜格式：【制作】→【画面】分步骤 →【参考图/资产】
- **不写**制作原因、版本修改注记、内部评审备注
- 术语统一（同一个东西全片用同一个名字）

### 3c 英文台词
- 给英文版 + 标注断行位置（考虑竖屏字幕溢出）
- 口语化：法官要有法官腔，夫妻吵架要有吵架味

## Step 4: 写入飞书在线表格
直接写到用户指定的飞书表格里新增 Sheet。**不在本地建 Excel。**

格式对标 UA 团队交付标准：
| 行 | 内容 | 格式 |
|---|------|------|
| 1 | 需求人 / 核心卖点 / 尺寸 / 时长 / 参考图 | 灰底粗体标签行 |
| 2 | 口播要求 / BGM / 音效 / 参考视频 | 灰底标签行 |
| 3 | 概述（中文剧情梗概） | 合并单元格 |
| 4+ | 分镜内容 | 灰底标题栏 + 合并内容区 |

## Step 5: 出参考图提示词
每镜给 Gemini Imagen 提示词。
**强制统一风格：** 全部 stylized 3D（Pixar/DreamWorks 级别）。
人类角色和游戏生物必须在同一个视觉世界。

## Step 6: 自检
假设自己是美术，打开这个 Sheet：
**30 秒内能说清这个片子讲了什么吗？** 不能 → 概述没写好，回去改。

---

## 关键红线

1. **不虚构游戏机制** — 喂食系统？刷新率？先确认游戏里有没有
2. **不碰 IP trade dress** — 宝可梦红白球、Judge Judy 波波头+蕾丝领、任何具体节目名称
3. **概述先于分镜** — 方向不对，分镜白写
4. **飞书优先于本地 Excel** — 用户不要一堆本地文件
5. **术语全文统一** — creature / Palkie / 幽飘 选一个用到底
