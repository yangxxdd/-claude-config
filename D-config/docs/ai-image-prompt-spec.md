# AI 生图提示词写作规范（全局）

> **触发**：用户要求写 AI 生图提示词（文生图 / 垫图参考）时，中文、英文都按本规范结构化输出。
> **目标**：一张图 = **设计一张图**，不是"描述一个人 + 一个背景"。之前的毛病是"模板味"，根因是缺了配色 / 材质 / 氛围 / 景深四个维度。

## 一、核心原则

1. **维度隔离 + 穷举**：把图拆成固定维度，每个维度精确写，AI 不跑偏、不脑补。
2. **拒绝含糊词**：不写"精致细节""温馨氛围"这种空话，每个词落到具体视觉（丝绸光泽、玻璃反光、汗液）。
3. **中英双语、结构一致**。

## 二、九大维度（按需取舍，但缺哪块要意识到"我漏了"）

| # | 维度 | 写什么 | 常见缺漏 |
|---|------|--------|---------|
| 1 | 场景 | setting(场景结构) + crowd(背景人物/氛围) + lighting(灯光方案) | 只写"XX内景"一句 |
| 2 | 主体 | appearance(外貌) + action(动作) + expression(表情) | 只有外貌 |
| 3 | 配色 | 6 色穷举：主光 + 主体色 + 背景色 + 点缀色 + 肤色 + 文字色 | 完全不写 |
| 4 | 构图 | 机位(仰/俯/平) + 焦点(主体锐利) + 景深(背景虚化/逆光轮廓/运动模糊) | 只写"占X%" |
| 5 | 氛围 | 4-6 个精确情绪词 | 只写"温馨"一个含糊词 |
| 6 | 文字 | 位置 + 具体文字 + 字体质感(金属3D/发光描边) + 文字背景 | 只写"顶部大字" |
| 7 | 材质 | 丝绸光泽 / 玻璃反光 / 金属 / 汗液 / 肌肉 | 完全不写 |
| 8 | 特效 | 光爆 / 粒子 / 技能光效 + 强度 | 堆特效没强度 |
| 9 | 风格 | 渲染方式 + 时代氛围 + 饱和度 | 只写"二次元" |

## 三、输出格式

- **中文**：自然语言、按维度分小段（不套 JSON，让即梦/可灵直接吃）。
- **英文**：对应翻译、同结构。
- **结尾固定**：文字排除声明——「除 XXX 外不要其他任何文字」。

## 四、反面清单（旧毛病，别再犯）

- ❌ 一句话流水账，全挤一段
- ❌ 不写配色方案
- ❌ 不写材质质感（只会写"精致细节"）
- ❌ 氛围只写一个含糊词
- ❌ 构图只写"占X%"，不写景深/焦点/逆光
- ❌ 主体只有外貌，无动作表情

## 五、结构骨架（照着填）

```
场景：[setting + crowd + lighting]
主体：[appearance + action + expression]
配色：[6色：主光/主体/背景/点缀/肤色/文字]
构图：[机位 + 焦点 + 景深]
氛围：[4-6 个情绪词]
文字：[位置 + 具体文字 + 字体质感 + 文字背景]
材质：[丝绸/玻璃/金属/皮肤…]
特效：[类型 + 强度]
风格：[渲染方式 + 时代氛围 + 饱和度]
结尾：除 XXX 外不要其他任何文字。
```
