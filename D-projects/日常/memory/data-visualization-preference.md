用户对数据可视化有很高期待。末日营地 FB 吸量测试报告中的图表（6 面板仪表盘、CTR 排名柱状图、CPM vs CTR 气泡散点图、年龄热力图等）获得好评。

## 可视化工具链
- **matplotlib** + Microsoft YaHei 字体渲染中文
- 图表通过 `lark-cli docs +media-insert` 或 `docs +update` 的 `<img>` 标签插入飞书文档
- 简单图表可用 `<whiteboard type="mermaid">` 内嵌

## 行为准则
- **主动建议**：在做数据分析、报告、展示时，主动思考是否有比纯文字/表格更好的可视化方式
- **偏好多样图表类型**：柱状图、散点气泡图、热力图、仪表盘等都受欢迎，不要只局限于一种
- **图表要能独立讲故事**：标注关键数据点、用颜色区分、添加结论性标题
- **可以大胆尝试**：用户对新颖的图表表达方式持开放态度，不需要保守

**Why:** 用户认为好的图表能让报告更直观、更专业，尤其在向领导汇报时更有说服力。
**How to apply:** 每次做数据相关的任务时，在规划阶段就考虑可视化方案，主动向用户提议，而不是等用户要求。
