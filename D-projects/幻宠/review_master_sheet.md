## 6. 构建脚本代码问题（非功能性）

### 6.1 运算符优先级缺陷（Line 308）

```python
if is_dup and '场景展示' in name or '高效抓宠' in name or ...
```

由于 Python 中 `and` 优先级高于 `or`，实际解析为：
```python
if (is_dup and '场景展示' in name) or '高效抓宠' in name or ...
```

这意味着"高效抓宠""核心玩法""天灾重建""抓宠战斗""海啸"不加 `is_dup` 判断即可标记，仅"场景展示"需要 `is_dup`。

**当前影响**：无。本数据集中这 6 个素材均在 4 月和 6 月同时出现（`is_dup=True`），未触发错误行为。但如果未来新增同名素材仅出现在单月，可能出现误标记。

**建议修复**：
```python
if is_dup and any(kw in name for kw in ['场景展示', '高效抓宠', '核心玩法', '天灾重建', '抓宠战斗', '海啸']):
```
