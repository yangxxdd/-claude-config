## 4. 上次测试（6/11）完整基线

> 数据源：① 6/11 测试计划 PDF（计划）；② 飞书「6月11日幻宠测试」表（实际，12 子表）。

### 4.1 计划设计（6/11 PDF）

**A. 三留测试（留存验证）**
- 测试期 6/11-6/21（10 天），投放期 6/11-6/13（3 天）；平台 Android、国家 US。
- 预算 $5,850 / 3 天；方法=控制变量（沿用 4 月 TA + 素材）；目的=检验产品 3 日版本留存。
- 投放架构（`PALKIE-GP-US-FB-AAA-INSTALL-MICHELLE` 体系下）：
  | 优化方式 | 目标定向 | 日量级 | 成本预估 | 日预算 | 总量级 | 总预算 |
  |---|---|---|---|---|---|---|
  | Install | AAA | 150 | $5.00 | $750 | 450 | $2,250 |
  | AEO | 核心用户 | 150 | $8.00 | $1,200 | 450 | $3,600 |
  | **合计** | | | | | **900** | **$5,850** |
- 目标 KPI（分级标准）：Install 优秀 ≤$5（R1>25%、R3 12%）；合格 $5-6（R1 20-25%、R3 8-10%）；待改进 >$6（R1<20%、R3 8%）。AEO 优秀 ≤$8（R1>30%、R3 13%）；合格 $8-9.6（R1 25-30%、R3 10-12%）；待改进 >$9.6（R1<25%、R3 10%）。
- **4 月三留基线（分级参照）**：Install **$3.96** / R1 26.74% / R3 11.79%；AEO **$5.89** / R1 32.70% / R3 13.84%（6/11 PDF 引用 4 月测试数据）。

**B. 素材方向测试（分测赛马）**
- 预算 $7,500 / 3 天（Install AAA 500/day × 3 = 1500 量级）。
- 方法：**2 个广告系列并行** —— 系列 1 按 5 个素材方向分组（每方向 $500/day，保方向覆盖）；系列 2 全部素材打一个包（$500/day，打包赛马筛最优）。
- 架构：抓宠经营 4V / 宠物展示 2V+4P / 模拟经营 4V+2P / 帕萌战斗 3V / 23 条素材，各 $500/day。
- 素材评估标准：4 月基准 $3.96 / CTR 1.8% / CVR 26.88% / R1 27.7%；优秀 ≤$5 ≥2% ≥26% R1 25%；合格 ≤$5.5 1.5-2% ≥24% R1 25%；待改进 >$6 <1.7% <22% <25%。

**C. 商店图更换（8 条调整思路）**
① 氛围图帕基与 ICON 建立联系；② 放大帕基及角色形象（突出宠物）；③ 文本框易读性；④ 新增抓宠捕捉卖场图；⑤ 帕基进化单独出图；⑥ 收集内容补 SSR 帕基表现；⑦ 突出模拟经营、弱化 SLG 感；⑧ 繁育/孵化单独出图。

### 5.2 已验证结论（可直接复用）

1. **最佳素材公式（跨 1月/4月 双重验证）**：视频开头「**获取宠物剧情**」→ 中间「战斗&升级」→「打 BOSS」。**剧情 > 玩法展示**——只要前期有获取宠物剧情，吸量能力最高（卡牌+剧情比帕鲁战斗 CPI 低 60%）。
2. **画风**：新画风全面胜出（量级+35%、CPI -30%），且年龄覆盖更宽（25-54）。
3. **副玩法分区域**：数字门（美 $3.74 最佳）/ 搜索射击（菲 $0.2 最佳）；必须分区域选。
4. **AEO 点位**：**tur7（~6分钟进游戏）次留 39.69%，比 Install 高 11pp**，最优；AEO 对素材要求更高（点击率低 30%），需保证事件量级让算法完成学习。
5. **区域用户素材偏好**：菲 Install 泛用户偏好模拟经营/建造/华丽爽感战斗，反感「AI开头+UE画风不统一」；AEO 用户偏好宝可梦题材+简单抓捕。
6. **留存 vs 吸量错位**：P-幻想宠物3、帕基世界冒险（像素风）吸量可但次留差（~15%）；重度/男性向素材（抓宠+战斗、海啸、建筑升级）留存高。
7. **3 秒定 CTR**：CTR 高的素材 3 秒播放率都高。

### 5.3 用户画像基准（供投放定向）

- **美国**：核心 25-54 岁（35-44 最多，~37%），男女 6:4~7:3，激活成本 ~$4.4。
- **菲律宾**：核心 25-34 岁，44 岁以下 90%，男性 80-90%。
- 副玩法/数字门吸引更高龄用户；重度向素材偏男性，宠物展示类偏女性。
