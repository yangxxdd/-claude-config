> **版本**：V1.0（待评审） | **日期**：2026-08-10 | **撰写**：投放侧
> **汇报对象**：王总 / 秦总 / 制作人
> **数据基线**：6/11 测试实际（飞书「6月11日幻宠测试」）、4 月留存测试、竞品 Sensor Tower 数据
> **一句话**：先花 $1.3 万复测留存（7 天），达标后开万人大服验证付费模型（14 天+），两阶段之间用复盘会门控。

## 一、测试总览

### 1.1 两阶段门控结构

```
阶段一：留存复测（D1-D7，~$13,000）
  ├─ 沿用 6 月 Install+AEO 出价方式，控制变量对比 6 月基线
  ├─ 70/30 双 Campaign：主买量 + 新旧商店图 AB
  └─ Install 先行起量 → 再开 AEO
        ↓ D8 复盘会（R1/R3/CPI 三维分级，人工拍板，不设死线）
阶段二：付费模型验证（万人大服，三档预算）
  ├─ 保守档 5,000 人 / 标准档 10,000 人 / 激进档 20,000 人
  ├─ 核心输出：破冰付费率、付费率、ARPU、付费结构、LTV 雏形
  └─ 硬门槛：付费埋点（商品ID/类型ID/是否首充）确认上线
```

## 三、阶段一：留存复测（D1-D7）

### 3.1 设计原则

- **控制变量**：TA 定向、出价方式、优化事件与 6 月完全一致，唯一变量 = 新版本 + 商店图 + 新素材，确保留存读数可与 6 月直接对比。
- **Install 先行**：D1 只开 Install，累计新增达 ~300 后（预计 D2）再开 AEO。理由：①Install 快速起量铺底，②AEO 需要事件密度完成学习，③无论 AEO 优化新手引导还是付费，都依赖前置量级。
- **新素材混跑不独测**：本次不设独立素材赛马模块（6 月已跑出方向结论：宠物展示/抓宠经营优、模拟经营差）。新做素材直接混入主 camp，由 Meta AAA 自动赛马，跑出来即为验证。

### 3.2 投放架构（70/30 双 Campaign）

| Campaign | 预算 | 占比 | 商店图 | 优化方式 | 目的 |
|---|---|---|---|---|---|
| **A · 主买量** | $9,100 | 70% | 旧版三建图 | Install → AEO | 留存主读数 + 量级主力 |
| **B · 商店图 AB** | $3,900 | 30% | 旧图 / 新图各半 | Install only | 新旧商店图 AB 判定 |

**Camp A 拆分**：

|---|---|---|---|---|---|

**Camp B 拆分**（Install only，AAA 定向）：

> AEO 事件选 **level_4_achieved**：6 月对比中优于 tutorial_5_achieved（CPI $8.34 vs $8.67，CVR 33.20% vs 28.60%）。

- 任一 🔴 → 不进阶段二，先查问题（版本/素材/新手漏斗），待下一版本

### 3.6 商店图 AB 判定规则

- **主读数**：落地页 CVR（B1 vs B2），辅读数 CPI、R1。
- 每组 ~260 新增，可检出 ≥5pp 的 CVR 差异；**差异 <5% 不判，维持旧图**（主流程稳定优先）。
- 新图 CVR 提升 ≥8% 且 CPI 不劣于旧图 → 新图胜出，阶段二导量全量切新图。
- 新图 R1 明显劣化（-3pp 以上）→ 即使 CVR 胜出也不切换，回查新图是否带来预期外用户。

### 3.7 关停规则（投放期执行）

| 条件 | 动作 |
|---|---|
| Install 组：花费 >$80 且激活 = 0 | 立即关停 |
| Install 组：CPI >$11 | 关停 |
| AEO 组：花费 >$120 且事件 = 0 | 立即关停 |
| AEO 组：CPI >$13 | 关停 |

| 单素材 CPI 超组均值 50% 且量级 <10 | 关停，预算让位 Top 素材 |

## 四、阶段二：付费模型验证（万人大服）

### 4.1 定位

- **目的**：不是冲 ROI，是**建立付费基线**——破冰付费率、D7/D14 付费率、ARPU、ARPPU、商品类型付费分布，拼出 LTV 雏形，回答「$8-9 的 CPI 能不能被回收模型支撑」。
- **形态**：单服万人大服（生态真实，付费行为不受鬼服稀释），美国 Android。
- **观测窗口**：投放结束后继续观察到 **D14**（付费模型最短有效窗口）。

### 4.2 三档方案（复盘会按阶段一结果选定）

| 档 | 触发参考 | 量级 | 日买量 | 投放天数 | 预算（CPI $8-9.5） |
|---|---|---|---|---|---|
| 保守档 | 阶段一「合格」 | 5,000 人 | ~750 | 6-7 天 | **$4.0-4.8 万** |
| 标准档 | 阶段一「良好」 | 10,000 人 | ~1,300 | 7-8 天 | **$8.0-9.5 万** |
| 激进档 | 阶段一「优秀」 | 20,000 人 | ~2,400 | 8-9 天 | **$16-19 万** |

> CPI 假设较阶段一上浮（量级放大通常推高 CPI 10-20%）。三档均含 10% buffer。
> 即使保守档（5,000 人），付费样本也可支撑破冰率/付费率读数（按 3-5% 付费率估 150-250 付费用户）。

### 4.3 投放结构

| 要素 | 方案 |
|---|---|
| 优化时序 | Install 起量铺底（D1-D2）→ 开 AEO-付费事件（首充），AEO 预算占比逐步提至 40-50% |
| AEO 事件 | **首充事件**（依赖埋点「是否首次充值」字段，为阶段二硬门槛）；若首充事件密度不足完成学习，降级用 level_4_achieved |
| 商店图 | 阶段一 AB 胜出版本 |
| 素材 | 阶段一 Top 素材为主力 + 新素材持续混入迭代；帕基战斗类素材视研发放出顺序补位 |
| 开服承接 | 200 券欢迎邮件（需本地化确认 + 研发单独配置）+ 游戏内公告 |

### 4.4 付费观测指标（埋点支撑）

| 指标 | 口径 | 用途 |
|---|---|---|
| 破冰付费率 | 激活 → 首次充值转化 | 付费模型第一问 |
| 破冰时长分布 | 激活 → 首充耗时 | 新手期付费引导效果 |
| D1/D3/D7/D14 付费率 | cohort 累计 | 付费深度曲线 |
| ARPU / ARPPU | 分 cohort | 收入能力 |
| 商品类型分布 | 月卡/周卡/常规礼包/活动（商品类型ID） | 付费结构健康度 |
| LTV7 / LTV14 | cohort 累计收入/新增 | 与 CPI 对比出回收线 |

**回收决策框架**（具体线由复盘会结合长线模型定，本计划不设死数）：LTV14 / CPI 得出 D14 回收率 → 对照同类产品 D14→D90 回收外推 → 输出「可放量 / 需调优 / 暂停」三选一建议。

## 七、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| CPI 继续上涨（6 月已较 4 月 +77%） | 量级不达标 | 预算含 10% buffer；关停规则兜底防失血；D3 量级缺口 >20% 时评估延长 1 天投放 |
| 付费埋点延期 | 阶段二无法启动 | 阶段一不受影响（留存不依赖付费埋点）；阶段二顺延，宁可等埋点不可裸跑 |
| 包体 826M 过大 | CVR 天花板、CPI 偏高 | 已列入研发优化排期；阶段二前争取瘦身 |
| 新商店图 AB 读数不显著 | 无法判定 | 差异 <5% 维持旧图，不纠结；新图元素拆入后续迭代 |
| 新手漏斗二次天灾流失点未改善 | 留存不达标的最大嫌疑 | 复盘会先看漏斗 75 步对比（6 月二次天灾单步流失最大：56%→43.7%），定位是版本问题还是投放问题 |
| IP 合规（任天堂形象） | 素材被拒/下架风险 | 上线前自查，主推原创帕基形象素材 |
| 阶段二单服生态不及预期 | 付费数据失真 | 保守档先跑 3 天看服务器生态指标，再决定是否续量 |
