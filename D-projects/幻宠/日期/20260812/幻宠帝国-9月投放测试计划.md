## 二、阶段一 · 七天留存测试（9/8-9/11）

### 2.1 测试目的

1. **验证前7天留存 vs 6月基线是否提升**：6月 Install R1 23.20%、AEO R1 29.67%，本轮目标 Install R1 >30%、AEO R1 >35%。
2. **验证新素材方向吸量/留存信号**：Camp1 8 个新脚本素材（融合/蹭超能勇士/蹭数码宝贝等）+ 宝可梦题材新素材（新广告组）。
3. **验证新商店图 AB**：新旧商店五图各半，判断阶段二导量用哪套图。
4. **验证 AEO 留存上限**：AEO `level_4_achieved`（6月已优于 `tutorial_5_achieved`：CPI \$8.34 vs \$8.67、CVR 33.20% vs 28.60%）。

## 六、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| CPI 继续上涨（6月较4月 +82%，\$4.42→\$8.05 口径） | 量级不达标 | 预算含 buffer；关停规则兜底；D3 量级缺口 >20% 评估延长 |
| 付费埋点延期 | 阶段二付费读数缺失 | 阶段一不受影响；阶段二顺延，宁可等埋点不可裸跑 |
| 宝可梦 IP 合规（任天堂形象） | 素材被拒/下架 | 上线前自查，优先原创帕基形象 |
| 阶段二 AEO purchase 事件密度不足 | 无法完成学习 | D2 起量保证 300+/天；不足则降级用浅层事件 |
| 菲律宾/T3 量级过大稀释美国读数 | 留存/付费失真 | 阶段二美国与补充量级分开 camp，独立读数 |
