# 03-A 提示词 V3（单场景叙事：投入美钞解锁产业）

## 核心改动（V2 → V3）
- V2 问题：手指/角色拖钱 + 绿色轨迹 + 房间点亮 + 产出面板 = 四个独立元素，功能演示感
- V3 方案：把"投入美钞解锁产业"写成**一个连贯场景中的动作**——女牛仔站在刚解锁的产业前，美钞从她手中正投入，产业门刚打开、生产启动，她正要走进解锁的产业
- 三段因果（投→解锁→产出）用**一个空间里的连续动作**表达，而非四个分区
- 单场景叙事：解锁产业是"真实的地方"，美钞是"她手里的动作"，产出是"门内亮起的生产"
