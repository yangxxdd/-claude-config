# 01-A 提示词 V3（贴合制作人意图：炸鸡店掩护武器交易）

## 与 V2 的核心差异
1. 场景逻辑从"炸鸡店 vs 夜城"改为"炸鸡店是伪装，店内暗藏武器交易"
2. 加入标志性双面动作：店员/女牛仔一手举炸鸡腿，一手从柜台下递出枪械
3. 加入店内暗藏细节：炸鸡盒藏枪、货架下露出武器、隐藏通道/监控摄像头/后门
4. 画风从"卡通3D"改为"美漫写实"（American Comic Realism，类似《蝙蝠侠阿卡姆》《看门狗》）
5. 保留用户已认可的：UI体系 + 霓虹夜城背景 + 明亮犯罪喜剧调性

[前景·双面身份时刻] 柜台后一位肌肉结实的店员（白衬衫+红围裙）笑容灿烂，一手高高举起金黄炸鸡腿作为友好招呼，另一只手却从柜台下偷偷把一把黑色手枪递给一位穿深色战术夹克、戴帽子的顾客；顾客平静地把一个黑色硬壳公文箱放到柜台上作为交换。柜台边缘下方隐约可见一叠现金和另一把武器的枪口。这就是"用炸鸡作掩护的隐秘交易"的标志性时刻。

[中景·店内] 明亮的美国炸鸡店：红黄配色的"FRIED CHICKEN"门头招牌、玻璃展示柜里摆满金黄炸鸡/汉堡/饮料、柜台后锃亮的钢制炸炉。货架上的食品盒下悄悄露出枪管；一个隐藏暗门或半掩的后门暗示秘密通道；角落有小型监控摄像头俯视店内。金黄鸡腿在空中飞舞（悬浮资源数字22、16）。真实材质：砖墙纹理、玻璃反光、钢材、电影级布光。

[背景] 透过店内玻璃窗，黄昏转夜的霓虹城市：紫蓝渐变天空、棕榈树与高楼剪影、远处品红与青色霓虹灯牌、一辆警车红蓝警灯在远处闪烁；一条亮黄色路线蜿蜒穿过街区，一个红色圆形事件针钉在地图上。城市灯光散景营造景深。
