# 05-A 提示词 V2（优化：战场纵深与规模感）

## V1 → V2 优化要点
1. 加战场纵深：远处战斗烟雾、多层建筑/楼梯/屋顶地形
2. 加环境破坏：燃烧车辆、破损路障、弹坑
3. 加战术动作多样性：卧倒、投掷、换弹、掩体转移
4. 保留已验证：12人双向交火 + 门徒领袖 + 右上占领掉落 + 不血腥
