# 08-A 提示词（营救情人复仇·救援紧迫）

## 方向定位
- P1 定向 | 中文：救她，然后开战 | 英文：SAVE HER. START A WAR.
- 制作人意图：三段叙事"危机→点击救援→后果"；必须迅速回到GTS真实城市行动与战斗
- 场景：左上情人受伤被困（围困/受伤，非束缚/暴露）→中央手指点按救援→右下门徒与小弟冲入街区；红色倒计时+黄色路线强化紧迫感；A版强调救援紧迫
- 禁区：不用束缚/暴露/性暗示；改成受伤被围困犯罪现场不误导成人内容
- 参考：08-研发参考-营救情人（游戏内限时治疗任务）

[右下·后果] 门徒与小弟冲入街区，武器就绪，与困住她的敌人交战。救援直接导致复仇——帮派战争开始了。从救援到战斗的过渡是即时且清晰的。
