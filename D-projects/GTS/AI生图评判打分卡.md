# AI 生图评判打分卡（执行质检）

> 定位：**纯执行质检**，回答「AI 生成的图做对了没有、合不合格」。
> **不判吸量/吸引力**——那是《GTS买量素材判断标准-v3》创意层的活。
> 一句话分工：**v3 管「值不值得做」，本卡管「做得对不对」。**

---

## 一、在完整流程中的位置

```
【创意层】写图片需求/脚本 → v3 判：吸量机制强不强？值不值得做？
                                    ↓ 强才往下
【执行层】写提示词（双语）→ 判：主体/景别/风格/构图/UI/背景/特效/文字策略 写清没？
                                    ↓
【执行层】AI 生图 → 本卡判：图对不对、合格不合格？（纯质检）
                                    ↓ 质检合格
【创意层】回看这张图 → v3 判：冲击力/吸引力够不够？
                                    ↓
              结论：可用 / 修图 / 重生成 / 重写需求
```

---

## 二、打分前先定场景（用途决定硬伤标准）

同一种表现，不同场景合理性不同。**黑线分割：漫画分镜 OK，商店图就是硬伤。**

| 场景 | 硬伤标准 |
|------|---------|
| **商店图** | 要真实一体，黑线/分镜式硬分割 = 硬伤 |
| **投放图片素材** | 可夸张可分镜，但要一眼看懂卖点 |
| **视频参考图**（角色/场景） | 关键是角色一致、能当制作参考 |
| **漫画/分镜图** | 黑线分镜合理，不算硬伤 |

## 三、五大维度（100 分）

| # | 维度 | 分值 | 看什么 | 常见扣分 |
|---|------|------|--------|---------|
| 1 | 描述还原 | 25 | 主体/景别/风格/构图/UI/背景/特效 按提示词还原了吗 | 景别错 -5；风格偏 -5；构图错 -5；漏关键元素 -5~10 |
| 2 | 逻辑合理性 | 25 | 元素是否凭空堆叠、违反物理/场景逻辑 | 物理逻辑错（光照/重力/透视）-5~10；无关元素堆叠 → 硬伤 |
| 3 | 画面完整性 | 20 | 结构一体吗、过渡自然吗、有无硬分割/断层 | 上下结构不一体、过渡生硬 -10；局部拼接感 -5 |
| 4 | 技术瑕疵 | 15 | 手指/文字/肢体/透视/多肢（**参考图阶段权重下调**，美术会重制，不为它一票否决） | 手指略怪 -5；透视错误 -5 |
| 5 | 场景适配 | 15 | 游戏感(UI够不够像游戏广告) + 冲击力(景别/特效/背景够不够抓人) | 游戏感不足 -5；冲击力弱 -5~10 |

## 四、硬伤项（出现即重生成/重写，不看其他分）

- 硬边/黑线把画面切成两半（**非漫画语境**）
- 肢体严重畸形 / 多肢 / 缺肢
- 文字乱码 / 伪文字
- 主体跑题 / 缺失
- 无关元素凭空堆叠

> 视频参考图额外加一条：**角色一致性**——同一角色多张参考图形象漂移 = 硬伤（视频 AI 生图最大的坑）。

### 硬伤的两条补充规则（实战沉淀）

**规则 A：文字乱码分档处理**

| 程度 | 处理 |
|------|------|
| 大面积、明显（满屏符号，如霓虹招牌 ♂♀□♡） | 重生成 |
| 局部、隐约、缩略图不可见（如肖像画框下小字） | **修图抹除**，别重生成 |

> 判据一句话：**伪文字在投放缩略图尺寸下看不见 → 修图；看得见 → 重生成。** 重生成是"整张重画"，有随机性，会连构图/动作/表现力一起变。

**规则 B：核心需求未达成 → 直接重生成，不看分数**

角色一致性（左右不是同一个人）、主体跑题、货不对板——这类"核心需求失败"，即使分数落在"修图"档，也**直接重生成/重写提示词**，因为修图（P脸/P主体）不划算也不可靠。

## 五、结果分档

| 分数 | 动作 |
|------|------|
| ≥85 | 可用，直接交付/投放 |
| 70-84 | 修图（小瑕疵可修） |
| 50-69 | 重生成（核心问题修不了） |
| <50 | 重写提示词（提示词本身没写清） |

## 六、示例（自证这卡能抓出之前漏的硬伤）

**案例：商店图「上下结构需过渡承接」，AI 用一道黑线硬切两半**

| 维度 | 判 | 说明 |
|------|-----|------|
| 画面完整性 | 硬伤 | 黑线硬分割，上下不是一体 |
| 场景适配 | 硬伤 | 商店图要求一体自然，不是漫画分镜 |
| 结论 | **重生成** | 之前忽视并给了高评分，是错的 |

**结论逻辑：** 质检合格 ≠ 有吸引力（那是 v3 的活）；但质检不合格（黑线硬分割）→ 先重生成，不用谈吸引力。

## 七、提示词精准度（生图前的自检，配合本卡用）

提示词写不好，生图必翻车。生图前先过这八问（风格/题材等开放集合按需指定，不设固定列表）：

| 要素 | 问什么 |
|------|--------|
| 主体 | 画什么、谁、什么动作/场景，清楚吗？ |
| 景别 | 主体特写/半身/全身/远景？占画面多大比例？ |
| 风格 | 渲染方式(写实/美漫/二次元/卡通/像素…) + 时代氛围(复古/赛博/现代…)，按需指定，说清楚了吗？ |
| 构图/镜头 | 低角度仰视/俯瞰/特写，焦点在哪？ |
| UI/游戏感 | 要不要游戏UI元素(稀有度框/按钮/进度条/货币/角标)？ |
| 背景 | 氛围方向 + 吸引力(营造氛围但别抢主体戏)？ |
| 特效 | 类型(光效/粒子/技能/升级光效) + 强度？ |
| 文字策略 | 要哪些数字/文字明确写，其余点名排除乱码（见下） |

**文字策略（不是"不要文字"）**：数字/文字是买量图的加分项，别一刀切砍掉。

| 素材类型 | 文字/数字策略 |
|---------|-------------|
| 命运反转/升级 | 要等级数字（如"标注清晰的 LV.60"） |
| 福利/数值 | 数字就是核心（收益数字、金额、+100%） |
| 反差萌/搞笑 | 可不要数字，靠画面喜感 |
| 悬念/抽卡 | 可要"十连""SSR"等稀有度数字 |

**写法**：要数字 → 明确写"XX位置标注清晰的数字 LV.60"，结尾"**除 LV.60 外**不要其他文字"；不要文字 → 点名排除文字载体（招牌/画/菜单/管道/包装用无字图案），不能笼统一句。

**附加**：背景若有肖像画/人物，加"原创人物，不模仿任何真实电影角色或明星"（防版权风险）。

**双语规范：** 中、英都给，结构固定「主体 + 景别 + 风格(渲染+氛围) + 构图/镜头 + UI/游戏感 + 背景 + 特效 + 文字策略」。
