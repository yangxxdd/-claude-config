# 买量素材判断标准 v3（通用骨架 + GTS 落地）

> 回答一个问题：**投之前，怎么判断一支素材的数据会不会好？**
> 数据是唯一裁判。这套标准是「投前预测」——把数据好坏，翻译成素材身上可检查的问题。
> 三层：**本质层（通用）→ 场景层（视频/图片）→ 题材层（GTS黑帮，幻宠/商店五图留接口）**。

---

## Part 0 · 30 秒怎么用

判断一条素材，走 6 步，每步一个「是/否」，答「否」触发动作：

```
① 定机制   这条靠哪种吸量机制让人停？
② 吸量自检 这个机制强不强？
③ 付费自检 有没有商业化钩子？筛得出付费用户吗？
④ 差异自检 相对竞品+自己历史，有新的吗？还是换皮？
⑤ 市场对标 广大大热度：这个方向近期在不在涨？
⑥ 自家数据 有没有历史底？怎么迭代/做变体？
→ 留存风险提示（不否决，投后盯数据）
→ 动作：放量 / 试点 / 迭代 / 砍
```

**产出动作（不是打分，是结论）：放量 / 试点 / 迭代 / 砍。**

---

## Part 1 · 本质层（跨游戏、跨场景通用）

好素材的三问，这是骨架，永远不变：

| 本质 | 投前看什么（素材特征） | 投后验证 | 权重 |
|------|---------------------|---------|------|
| **吸量力** | 吸量机制强不强（hook/悬念/画面冲击/反差） | CPI / CTR / CVR | 最高 |
| **付费** | 有没有商业化钩子、筛不筛得出付费人群 | ROI / LTV / 回本 | 高 |
| **差异化** | 表达形式/题材组合有没有新的 | 疲劳度 / 竞争挤压 | 中 |

**「承诺兑现」降级为留存风险提示**（不是否决项）：

- 假副玩法是买量常态——素材玩法只要和游戏「稍微有一点点关联」，即使不是核心玩法，只要吸量便宜、用户付费，就是好素材。
- 所以承诺兑现不否决素材，只标注：**承诺兑现程度低 → 留存可能低 → 投后盯留存数据**。
- 唯一警惕的极端：**完全无关到留存崩塌**（超速被抓，素材场景游戏里根本没有，次留 10.14%）。判它靠留存数据崩，不靠素材层面一票否决。
- GTS 是 3 留测试，留存是硬 KPI：这条风险要**标出来给产品侧看**，但当不当砍的理由。

## Part 2 · 吸量力怎么判（核心）

### 2.1 底层机制（相对有限，判断的核心）

形态枚举永远补不全。真正稳健的是「吸量机制」——让人在信息流里停下来的理由，基本就这几类：

| 吸量机制 | 让人停下来的理由 | 常见形态 | GTS 例子 |
|---------|----------------|---------|---------|
| 好奇/悬念 | 想知道后续 | 叙事反转、抽卡 | 晋级失败、招募表演 |
| 视觉冲击 | 好看/刺激 | 展示型 | 美漫分镜、绯夜立绘 |
| 代入/想玩 | 这说的就是我、我想玩 | 实录型 | 模拟经营录屏 |
| 情绪/好笑 | 反差/好笑 | 反差搞笑 | 炸鸡店 |
| 欲望 | 性/占有/贪 | 擦边、抽卡、福利 | 擦边酒吧 |
| 上瘾 | 重复+节奏洗脑 | 魔性 | 待开发 |

**判断核心：这条靠哪种机制让人停？这个理由强不强？**
- 哪种机制都靠不上 → 吸量力存疑，危险信号。
- 出现第 9 种形态？看它靠哪种机制让人停，自动归位。

### 2.2 形态清单（开放索引，不穷尽）

| 形态 | 靠什么 | 说明 |
|------|--------|------|
| 叙事型 | 剧情/命运反转 | hook 前3秒 + 转折 |
| 展示型 | 角色/立绘/AI画面 | 首帧冲击 + 卖点一眼懂 |
| 玩法实录型 | 录屏 | 核心玩法爽感直观 |
| 反差搞笑型 | 黑帮×日常 | 认知冲突够炸 |
| 悬念/商业化型 | 抽卡招募 | 赌博心理/占有欲 |
| 魔性/洗脑型 | BGM+画面鬼畜 | 重复+节奏上瘾 |
| 福利/数值型 | 榜单/福利码/数值 | 占便宜/确定性变强 |
| 擦边/氛围型 | 暧昧/禁忌 | 性暗示/窥探欲 |

> 清单是索引，不是全集。新形态按 2.1 机制归位。

## Part 3 · 场景层（视频 / 图片，生产链全覆盖）

### 3.1 视频素材

**分镜脚本评判（4 自检）：**

| 自检 | 问什么 | 为什么 |
|------|--------|--------|
| 吸量点位置 | hook 落在 S0-S2（前3秒）了吗？ | 2月结论：CTR 与 3秒播放率成正比 |
| 节奏推进 | 每镜有推进吗（钩子→展开→爽点→反转→CTA）？ | 45s 平铺 = 完播崩 |
| 可执行 | UE/AE/AI 真做得出吗？提示词精准吗？ | 写得出做不出 = 空头分镜 |
| 卖点落地 | 核心卖点真拍进画面了吗？ | 卖点悬空 = 素材白做 |

**视频的 AI 生图（角色/场景参考图）**：中间物料，不上信息流，判据换两条：
- 不看缩略图冲击力，看**「能不能当美术制作参考」**。
- 额外加**「角色一致性」**：同一角色（汤米/绯夜）多镜、多张参考图里形象不能漂移——视频 AI 生图最大的坑。

### 3.2 图片素材

**① 提示词精准度评判**（写得好不好，决定能不能精准出图）：

| 要素 | 问什么 |
|------|--------|
| 主体 | 画什么、谁、什么动作/场景，清楚吗？ |
| 风格 | 美漫/卡通/写实/二次元，点明了吗？ |
| 构图/镜头 | 低角度仰视/俯瞰/特写，交代了吗？ |
| 排除项 | 不要什么（如"不要文字"），写了吗？ |

**② 双语提示词规范**：中、英都给（适配 Gemini，以后换工具通用）。结构固定为「主体 + 风格 + 构图/镜头 + 光影 + 排除项」。

**③ AI 生图结果评判**：拆两层，各用各的尺子。

- **执行质检**（图对不对、合格不合格）→ 见《AI生图评判打分卡》：5维度（描述还原/逻辑合理/画面完整/技术瑕疵/场景适配）+ 硬伤一票否决 + 分档。**不判吸量。**
- **创意层**（图吸不吸量）→ 回到 Part 2 吸量力，判冲击力/吸引力。

## Part 4 · 题材层（GTS 黑帮落地）

### 4.1 GTS 已验证 hook 库

| hook 类型 | 已验证素材 | 数据 |
|-----------|-----------|------|
| 命运反转（顶→谷→反弹） | 晋级失败被捕 | CPI $1.56-1.79 三次最稳 |
| 反差萌（黑帮×日常） | 炸鸡店/披萨店 | CPI $1.37 全场最低 |
| 禁忌窥探（地下世界/仪式） | 浴血黑帮 | CPI $1.14 + AEO 次留 50% |
| 悬念（谁上场/抽不抽） | 招募表演 | D1 39.58%-53.3% |

### 4.2 GTS 竞品参照（广大大用法）

- 黑帮三巨头：Mafia City（收入第一）、The Grand Mafia（DAU 15.4万，**最值得对标**，R1 21.93%）、Idle Mafia（留存最好但衰退）。
- 4X 框架：Kingshot（R1 33.31% 新爆款）、Lands of Jail（监狱题材 W4 9.72%，验证「非战争题材+经营+SLG」可行）。
- **实操**：广大大按热度排序 + top1&top10，筛同题材（黑帮），看近期在投什么方向、什么形态。

### 4.3 GTS 自家数据地基

| 状态 | 素材/方向 | 一句话 |
|------|----------|--------|
| ✅ 已验证 | 晋级失败 | 命运反转公式，最稳 |
| ✅ 已验证 | 炸鸡店/披萨店 | 反差萌，Install 优先 |
| ✅ 已验证 | 浴血黑帮 | 氛围/禁忌感，CPI+留存双优 |
| ⚠️ 量小信号好 | 招募表演 | D1 高但 DNU 15-24 |
| ⚠️ 量小信号好 | 鸡公大侠 | D1 偶发 41%，CPI 不稳 |
| ❌ 已淘汰 | 超速被抓/战斗形式/越狱混剪/赌场博弈 | 货不对板/接不住点击/太贵 |
| ❌ 已淘汰 | 角色展示/立绘展示/主角展示 | 4月没量 |

**用数据的铁律：** 复刻「已验证」前，先回答「它为什么数据好」——是机制强？付费好？还是差异？答不出 = 换皮，打回重审。

## Part 5 · 决策流程（不打分，走 checklist）

```
① 定机制   靠哪种吸量机制让人停？（查 Part 2.1）
② 吸量自检 这个机制强不强？（按场景查 Part 3）—— 弱 → 砍/改
③ 付费自检 有没有商业化钩子？筛得出付费用户吗？—— 无 → 降优先级
④ 差异自检 相对竞品+自己历史，有新的吗？—— 换皮 → 打回
⑤ 市场对标 广大大热度，方向在不在？（查 Part 4.2）
⑥ 自家数据 有没有底？怎么迭代/变体？（查 Part 4.3）
→ 留存风险：承诺兑现程度低 → 标出，投后盯留存（不否决）
```

**综合动作：**

| 情况 | 动作 |
|------|------|
| ②③④ 都过 + ⑤顺大盘 + ⑥有底 | **放量** |
| ②③④ 都过 + ⑤顺大盘 + ⑥无底 | **试点** |
| ②③④ 都过 + ⑤逆大盘 | 谨慎试点（除非差异化红利大） |
| ② 不过 | **砍/改**（不管历史数据多好） |
| ②过 但 ③无付费钩子 | 试点，重点观察回本/ROI |

## Part 7 · 诚实缺口

1. **竞品素材层数据**：「市场对标」需要广大大按热度/top1&top10 拉黑帮 SLG 近期素材。我记忆里只有竞品产品数据（收入/DAU/留存），没有素材创意层实时在投动态。要落地，得先拉这份数据。
2. **样本小的方向**（招募表演、鸡公大侠）：「已验证」置信度有限，动作只能「试点」，不能「放量」。
3. **付费维度缺数据**：GTS 目前是 3 留测试，还没到付费验证阶段，所以「付费自检」暂时没有 GTS 自己的 ROI 数据支撑，只能靠竞品和商业化钩子逻辑预判。
