# 素材脚本创意引擎 v2

## 强制流程（每次必须按顺序走，不可跳过）

```
Step 0: 定位游戏与资产库
Step 1: 找参考（强制！外部竞品，不拿自己成品当参考）
Step 2: 创意提案（2-3 方案，轻量确认）
Step 3: 生成完整分镜脚本（每个镜头配资产引用 + 制作方式 + 原因）
Step 4: 质量自检
```

---

## Step 0：定位游戏与资产库

根据用户指定的游戏，确定资产库：

| 游戏 | 资产库路径 | 资产索引 |
|------|-----------|---------|
| 幻宠/宝可梦/幻想宠物 | `Y:\市场运营部\友蜜\幻想宠物` | asset_index.json → 幻宠 |
| GTS/黑帮/KOG | `Y:\市场运营部\友蜜\黑帮题材` | asset_index.json → GTS |

动作：
- 读取 `asset_index.json`，列出该游戏**物料&资产**目录下有哪些角色、场景、UI 可用
- 成品素材目录只看不引用——了解制作质量水平即可
- 如果库太旧（超过 2 周），先重新扫描物料&资产

## Step 1：找参考（强制！不可跳过）

### 重要区分
- **物料&资产** = 素材库（角色/场景/UI），告诉你能用**什么**来搭建 → Step 0 用
- **外部竞品素材** = 别人跑得好的广告，告诉你什么**套路**有效 → Step 1 用
- **自己的成品素材** = 已经做过的，**不作为新脚本的创意参考**。除非用户明确说"在之前 XX 基础上延伸"，否则不引用。最多用于了解制作质量标准。

### 1a. 外部竞品搜索（主要参考来源）
用 WebSearch 搜索该方向的热门竞品广告：
- 搜索公式：`[方向关键词] + 手游广告 + 最佳创意 + 2025/2026`
- 关注：钩子类型、视觉风格、叙事结构、制作方式
- 如果之前调研过同类方向，优先复用已有调研结果
- 如果用户提到在广大大等平台看到了具体素材，让用户发链接或描述

### 1b. 跨品类参考（当垂直方向找不到时）
如果该方向找不到直接竞品，从相邻品类找灵感：
- 同类玩法不同题材（如"融合"找不到→搜"进化""合成""升级"）
- 同类题材不同玩法（如"宝可梦"方向找不到→搜"怪物收集""宠物养成"）
- 完全跨界的叙事套路（如电影预告片、短视频热门模板）

### 1c. 参考摘要（在提案中展示）
```
## 参考素材（全部来自外部竞品/跨品类）
- [竞品/案例名] — [核心套路] — [为什么适合我们]（来源：[链接]）
```

### 1d. 参考适配分析（B 级改编——最常见的情况）

**大多数参考不能直接复刻。** 拿到用户给的参考后，先做四问拆解，再写脚本：

#### 参考难度分级

| 等级 | 情况 | 策略 |
|------|------|------|
| **A 级：直接复刻** | 玩法相同、题材相近、只换皮 | 拆分镜 → 替换角色/场景 → 微调 |
| **B 级：改编复刻** | 套路通用、但玩法/题材差异大 | 拆叙事骨架 → 替换内容 → 重写分镜 |
| **C 级：灵感提取** | 只有某个画面/片段能用 | 提取那个点 → 围绕它重新构建 |

#### B 级改编四问（写脚本前必须回答）

**Q1：它的钩子依赖什么？能不能迁移？**
> 例：Palmon "电锯断尾"依赖 3D 写实渲染，不能直接复刻到 2D 卡通。但**"对可爱生物施加暴力"的情绪机制是通用的**——换成卡通版表达（碎纸机、压路机）。

**Q2：它的卖点展示靠什么？我们有没有等效替代？**
> 例：参考用 3D 自由视角展示进化——你没有 3D 场景。但可以用现有 3D 角色序列帧 + AE 合成来模拟。

**Q3：它的节奏和时长适不适合我们的制作能力？**
> 参考里 2 秒切 5 个画面——美术做不到。需要降速拆解，5 个画面 → 3 个镜头 10 秒。

**Q4：它的情绪线能不能保留？**
> **情绪线是最不该改的。** 恐惧→好奇→震撼→满足，这条线保留——只换画面内容。

#### 用户标注

用户提供参考时会说"这里好"——**优先拆解用户标注的片段**，而不是整条视频。标注的部分决定了方向，其余部分围绕它构建。

## Step 2：创意提案

### 2a. AI/AE/UE 决策框架（不是拍脑袋，必须有原因）

| 制作方式 | 什么时候用 | 什么时候不用 | 你们实际案例 |
|---------|-----------|-------------|------------|
| **AI 生成** | ① 游戏里不存在的新角色/融合体/概念图 ② 视频前贴吸睛画面 ③ 剧情插画/静态叙事帧 | ① 需要连续动作一致性 ② UI 动画 ③ 3D 场景漫游 | 宠物合成展示(AI)、杀宠复刻(AI)、模拟经营7日延时(AI) |
| **AE 合成** | ① 已有图层素材需要组合+动效 ② UI 弹窗/数值跳动/转场 ③ 竞品复刻（替换素材+改尾贴）④ 2D 特效（粒子、发光、震动） | ① 3D 角色在场景中走动 ② 复杂的摄像机运镜 ③ 需要 UE 实时渲染的光影 | 竞品更换尾贴、抓宠战斗、收集升级、场景展示、天灾重建 |
| **UE 渲染** | ① 3D 场景+摄像机漫游 ② 角色在 3D 环境中动画 ③ 需要高质量实时渲染光影 ④ 已有 UE 资产可直接复用 | ① 需要快速迭代 ② 主体为 2D/UI ③ 没有现成 3D 资产 | 售卖帕基(UE)、拯救可达鸭(UE)、帕基庇护所(UE)、群殴打鸡(UE) |

**决策优先级**：优先 AE+AI 组合 → 只有必须用 3D 时才上 UE → 标注原因

**典型混合模式**：
- AI 前贴(0-3s 吸睛画面) + AE 主体(UI/转场/动效) = 最常用
- UE 场景(角色在 3D 环境中) + AE 后制(UI 叠加/尾贴) = 需要 3D 时
- 纯 AI 逐帧(剧情向/概念展示) = 不需要 UI 交互时

### 2b. 钩子公式（基于行业验证）

| 钩子类型 | 公式 | 适用场景 | 行业标杆案例 |
|---------|------|---------|------------|
| **震惊虐待** | 对可爱生物施加暴力/危机 → 观众不忍心划走 | 宠物/融合/进化类 | Palmon Survival（电锯断尾→恢复进化） |
| **反差打脸** | 被嘲笑/嫌弃 → 反转证明强大 | 升级/变装/战力类 | 你们自己的"小弟逆袭" |
| **禁忌悬念** | 警告/禁忌 → 好奇心驱动看完 | 融合/神秘玩法 | Gossip Harbor 式情感危机 |
| **竞技压迫** | 多人淘汰/生死局 → 紧张感 | 对战/竞技类 | 鱿鱼游戏式淘汰制 |
| **沙雕搞笑** | 拟人化卖萌/意外事故 → 笑就停不下来 | 泛用户/休闲类 | 你们的"鸡公大侠" |

### 2c. 叙事结构（30 秒标准模板）

```
危险/冲突钩子 (0-3s)   → 决定 CTR，必须极端
紧张升级    (3-15s)  → 问题加深，制造焦虑
转折/揭示   (15-25s) → 合并/进化/胜利，情绪释放
CTA        (25-30s) → 下载按钮 + 价值主张
```

### 2d. 提案输出格式

```
## 方案 N：[名称] — [钩子类型]
**参考来源**：[内部成品 X] + [外部案例 Y]
**剧情线**：[一句话概括]
**Hook (0-3s)**：[具体画面 + 为什么能抓住人]
**升级 (3-15s)**：[冲突如何加深]
**揭示 (15-25s)**：[转折/成功画面]
**CTA (25-30s)**：[号召行动]
**制作方案**：
  - AI负责：[具体哪些画面/角色需要AI生成] — 原因：[为什么]
  - AE负责：[具体哪些镜头/效果用AE] — 原因：[为什么]  
  - UE负责：[如果有] — 原因：[为什么]
**资产就绪度**：✅ [现成可用的] / ⚠️ [部分可用的] / ❌ [需新做的]
```

## Step 3：生成完整脚本

用户确认方案后，按他们模板格式生成 Excel 分镜表。每个分镜：

| 字段 | 要求 |
|------|------|
| 分镜编号 | 分镜一~五 |
| 时长 | 精确到秒，单个镜头不超 3 个动作 |
| 画面描述 | 美术能直接看懂的描述，不写抽象形容词 |
| 资产引用 | 精确路径 或 "需新做：[具体要求+画风+尺寸]" |
| 音效/BGM | 具体音效描述 |
| 制作工具 | AI/AE/UE + 原因（一句话） |
| 参考来源 | 这个镜头参考了哪个成品/竞品的哪个画面 |

## Step 4：质量自检

- [ ] 每个方案都标了参考来源？（内部成品 + 外部案例）
- [ ] AI/AE/UE 每个镜头都标注了 + 原因？
- [ ] Hook 是否属于已验证公式之一？（虐待/反差/禁忌/竞技/沙雕）
- [ ] 剧情有冲突有转折有成功画面？
- [ ] 时长总和正确？单镜头动作数合理？
- [ ] 每个镜头有资产引用或"需新做"标注？
- [ ] CTA 落到下载/商店页？
