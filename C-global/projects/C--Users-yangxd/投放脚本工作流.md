## Stage A：找参考 & 下载（用户负责）

### A1. 登录广大大

在自己平时用的 Chrome 浏览器（不是 Claude 的 Playwright 浏览器）打开：
`https://guangdada.net/modules/auth/login`

用你的子账号登录。登录一次后 Cookie 保留，下次直接进。

### A2. 进入素材搜索

登录后访问：`https://guangdada.net/modules/creative/display-ads`

### A3. 搜索框——注意有两个！

⚠️ **这是之前踩过的坑，很重要：**

| 位置 | 样子 | 能用吗 |
|------|------|--------|
| 页面**顶部**导航栏 | placeholder "搜索 创意 广告主 关键词" | ❌ **不能用！** 会跳到"全局搜索"，搜出来不是广告素材 |
| 页面**中间**素材筛选区 | placeholder "搜索广告主、文案、包名等关键词" | ✅ **用这个！** 旁边有"综合"下拉、"Top创意"等筛选条件 |

**用第二个搜索框。**

### A4. 筛选设置

- **时间范围**：近 30 天
- **排序**：热度 或 展示估值（按这个排才能找到跑的好的）
- **Top 创意**：先不开（太窄会零结果），搜到内容后再开
- **精确搜索**：关掉（太窄漏结果）
- **素材类型**：视频

### A5. 怎么判断素材好不好

**必须点进去看完整视频内容，不能只看封面。** 关注：

| 维度 | 看什么 |
|------|--------|
| 钩子（0-3s） | 能不能让你停下来？虐待/反差/悬念/恐惧/搞笑？ |
| 叙事结构 | 几段式？钩子→冲突→揭示→CTA 清晰吗？ |
| 表现手法 | 融合/抓宠/战斗怎么呈现的？特效类型？ |
| 情绪线 | 观众情绪怎么走的？（恐惧→好奇→满足） |
| 制作方式 | 看起来是 UE/AE/AI？占比？ |
| **跑量数据** | 人气值、投放天数、展示估值——这些在广大大卡片上能看到 |

### A6. 下载视频

找到好的素材后，在广大大页面下载到本地。存到一个固定目录方便我们读取，比如：
`C:\Users\yangxd\Downloads\竞品参考\`

### A7. 标注"这里好"

下载完告诉我时，顺带说一下你觉得哪里好。比如：
> "这条素材开头那个踢飞宠物的动作特别抓人"
> "中间那个融合光效做得很好，我们也可以做"

这个标注直接影响我拆解时的重点。

## Stage B：视频分析 & 参考适配（DeepSeek 负责）

### B1. 视频抽帧

用 OpenCV 对用户下载的视频逐秒抽帧，场景切换检测去重，保留 8-15 个关键帧。

### B2. 画面分析

用千问逐帧分析每个关键帧的画面内容，拼出完整分镜结构。

### B3. 输出视频分析报告

```markdown
## 素材分析：[素材文件名]

**时长**：[xx 秒] | **画风**：[2D/3D/卡通/写实]

### 分镜结构
| 时间 | 画面 | 阶段 |
|------|------|------|
| 0-2s | [描述] | 钩子 |
| 2-8s | [描述] | 冲突 |
| ... | ... | ... |

### 核心套路
[一句话总结创作公式]

### 用户标注的重点
[用户说了哪里好——重点拆这一段]

### 可复刻的元素
- [元素1]
- [元素2]
```

### B4. 适配分析（B 级改编四问）

**Q1：它的钩子依赖什么？能不能迁移到我们的画风？**
**Q2：它的卖点展示靠什么？我们有没有等效替代？**
**Q3：它的节奏适不适合我们的制作能力？**
**Q4：它的情绪线能不能保留？**

## Stage C：创意提案（DeepSeek 负责）

### C1. 读取资产库

读 `asset_index.json`，列出该游戏可用的角色、场景、UI。

### C2. 产出 2-3 个创意提案

每个方案包含：
- 参考来源（基于 Stage B 的分析）
- 剧情线（一句话概括）
- Hook / 升级 / 揭示 / CTA（每段具体画面+时长）
- AI/AE/UE 分工 + **每个决策的原因**
- 资产就绪度（✅现成 / ⚠️部分缺 / ❌需新做）

**等用户确认方向后进入 Stage D。**

## Stage D：生成完整分镜（DeepSeek 负责）

### D1. 输出格式

按用户模板生成 Excel，字段包括：
需求人、核心卖点、目标受众、视频尺寸、视频时长、口播要求、BGM、音效/特效要求、备注、分镜一~五

### D2. 每个分镜必须包含

| 字段 | 要求 |
|------|------|
| 画面描述 | 美术能直接看懂，不写抽象形容词 |
| 精确时长 | 单镜头不超过 3 个动作 |
| 资产引用 | 精确文件路径 或 "需新做：具体要求" |
| 制作工具 | AI/AE/UE + 原因（一句话） |
| 音效 | 具体描述 |

### D3. AI/AE/UE 决策规则

| 工具 | 什么时候用 | 不用的时候 |
|------|-----------|-----------|
| AI 生成 | 游戏里不存在的新角色/融合体/概念图、视频前贴 | 连续动画、UI 动画 |
| AE 合成 | 现有素材组合+动效、UI/转场、2D特效、竞品复刻 | 3D 场景漫游 |
| UE 渲染 | 3D 场景+摄像机、角色 3D 动画 | 快速迭代、2D/UI 为主 |

**优先级**：AE+AI 优先 → UE 仅在必须 3D 时使用 → 每次标注原因
