## 给幻宠的启示

1. **Palmon: Survival 是直接竞品**，Lilith Games 先发优势，需紧密跟踪其迭代
2. **宝可梦 IP 留存加成约 5pp**（Palmon R1=35.97% vs 4X 平均 ~30%），幻宠可设更高留存目标
3. **宝可梦 IP 女性用户比例更高**，可差异化做女性友好的 SLG 体验
4. **目标留存**：R1>35%，R7>15%，R14>10%，W4>12%（参考 Palmon 美国数据）
