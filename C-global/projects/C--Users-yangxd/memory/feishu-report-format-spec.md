用户觉得 WorkBuddy 这份报告（https://www.workbuddy.link/p/4nXGUjqn8CKARJfyup4VRh）"看着舒服"，让提取它的优点作为排版参考。**用户尚未决定是否以后固定按此规范走**，目前仅作为"好看的优点"记录，不是硬性规则，写作时可按需参考、不必强制执行。

可提取的优点：
- 结论前置：先 KPI 卡/结论，再评级表，最后明细
- 双市场（国内/海外）左右分栏并列，同指标对齐
- 档位化评级（T0/T1/T2、K0/K1/K2）+「核心原因」列
- 每表配「口径说明」脚注，写清公式/加权规则
- 一主色贯穿 + ≤2 辅助色；强调只用加粗/变色/成块三招
- 图表类型匹配数据（排名→横条、趋势→折线、双变量→柱+折线）
- 缺失数据显式标注，不硬凑
- 飞书复刻限制：渐变/阴影/圆角卡片无法做，图表需预生成 PNG 插入
