## 黑帮竞品总结

| 维度 | Mafia City | The Grand Mafia | Idle Mafia |
|------|-----------|----------------|------------|
| 发行商 | Yotta Games | Yotta Games | Century Games |
| 总规模 | 🥇 收入第一 | 🥈 第二 | 🥉 衰退中 |
| 当下活跃度 | 低(DAU 1.7万) | 中(DAU 15.4万) | 低(DAU 2.4万) |
| 留存质量 | 无数据 | 中等(R14 5.38%) | 🥇 最好(R14 9.56%) |
| 用户画像 | 62%男 25-34 | 71%男 25-34 | 74%男 18-34 |
| GTS 参考价值 | 品类标杆 | **最值得对标** | 放置融合参考 |

**GTS 的差异化机会**：
1. 黑帮品类无新产品冲击，三款均在衰退/成熟期
2. 指尖无双的框架 + 黑帮题材 = 市场空白
3. The Grand Mafia 是最高价值的对标对象（活跃用户最多、收入稳健）
4. 目标留存基准：D1>22%，D7>8%，D14>5%（参考 The Grand Mafia 美国）
