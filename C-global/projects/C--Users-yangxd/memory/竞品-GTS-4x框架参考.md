## 给 GTS 的启示

1. **指尖无双框架在国内验证过**，虽全球数据少但框架可靠
2. **Kingshot 证明**：Century Games 有能力同时运营多款 4X 爆款（Whiteout Survival + Kingshot）
3. **Lands of Jail** 是监狱/犯罪题材，与黑帮天然关联，应重点研究
4. **留存目标**：D1 30%+、D7 8%+、D14 5%+ 是 4X 品类及格线
