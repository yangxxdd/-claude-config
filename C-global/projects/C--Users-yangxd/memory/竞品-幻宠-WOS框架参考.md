## 框架关键特征总结

**WOS 框架 = 生存题材 + 4X SLG 核心循环**：
1. 基地建设 + 资源管理（木材/火炉/食物）
2. 联盟系统 + 大地图争夺
3. 英雄收集 + 养成
4. 赛季制 + 滚服

**幻宠差异化机会**：
1. 宝可梦 IP 替代生存题材 = 更大众、更女性友好
2. 宠物收集/进化 替代 英雄养成 = 天然的情感绑定
3. 精灵对战 替代 生存战斗 = 降低血腥感，扩大用户群
4. 宝可梦 IP 的社交媒体传播力远超生存题材
