用户用智谱清言（chatglm.cn）生成幻宠项目的买量素材与商店图参考图，曾因提示词写出暗黑史诗风、跑偏成4X SLG而严重不满意。以后给该项目写AI生图提示词必须遵守：

**Why:** 幻宠真实物料是全程明亮Q萌3D卡通风；清言不认英文游戏名风格锚点，且长提示词丢元素、AI写字必乱码。

**How to apply:**
1. 风格底座（每条开头必带，替代英文游戏名）：「明亮清新的3D卡通渲染画风，皮克斯动画质感，圆润Q萌的原创奇幻宠物造型，糖果色系高饱和度，明亮日光与柔软光影，精致材质细节，顶级休闲手游美术品质，童话治愈氛围。」
2. 单焦点：一图一个焦点动作，元素≤6个，重要元素前置
3. 明度纪律：史诗感靠特效亮度+体型对比，绝不压暗背景
4. 品类锚定：地图/战争场景必须写"宠物组成的军团、卡通城堡"，防跑偏成写实4X
5. 文字零容忍：提示词写"无文字"，UI只画框架，文案后期合成
6. 每张图指定15%干净留白区
7. 买量素材要冲突/悬念/对比；商店图像"精修实机截图"
8. 用户无后期合成能力，走"路线B"：slogan直接写进提示词让AI渲染（清言简短英文大字可渲染，词越短成功率越高，&符号易错可改AND），每张抽卡4-8次挑字全对的
9. 吸引力三要素（用户反馈"好看但不抓人"的根因）：①主体英雄化——主角占画面1/4~1/3、低角度、有情绪，忌全家福式站位；②动作峰值化——定格"即将发生"瞬间，忌平静摆拍；③视觉锚点——大黄字slogan+血条/图标游戏感元素，忌干净插画

10. 套图版式规范（用户反馈"文案一会上一会下、不像一套"的根因）：一套商店图必须把同一段版式模板一字不差写进每条提示词——「上方约五分之四为游戏场景插画，底部约五分之一为标题区，深色半透明渐变衬底，正中央一行大号粗体立体英文标题，金黄色渐变字、深蓝色描边、带投影，标题严格固定在画面底部」。单图写法位置（顶部/底部）绝不能张张不同
11. 背景单薄对策：每张图加环境道具清单（小径/栅栏/水车/水晶簇/灯笼等）+前景虚化遮挡构图（草叶/花瓣），画面才饱满
12. 清言文字/版式控制不稳时，同一套提示词可平移到即梦3.0（文字渲染更强），提示词不用改
