## 一、1月吸量测试（1/29 - 1/31）

### 测试设置
- **预算**: $1,600（实际花费 $1,199.87）
- **区域**: 美国 + 菲律宾
- **渠道**: Facebook
- **出价**: install
- **受众**: SLG/建造&经营/策略 ∩ 宝可梦系列 ∩ 手游用户，男女不限，年龄不限
- **规则**: 每条素材等量曝光；若某广告完成学习后 CPI > 均价的 2 倍，可提前关闭

### 核心结论

| 结论 | 详情 |
|------|------|
| 🇺🇸 美国 CPI $5（不含竞品） | 位于 SLG 策略品类 CPI $3.5-$5 边缘；竞品莉莉丝 Palmon Survival CPI 仅 $0.84 |
| 🇵🇭 菲律宾 CPI $0.35（不含竞品） | 高于品类均值 $0.2；竞品 Palmon Survival $0.13 |
| 🎮 副玩法验证 | 美国【数字门】CPI $3.74、菲律宾【搜索射击】$0.20，均落在行业均值内 |

### 整体数据
- 总花费: $1,199.87，激活量: 998
- 美国: 359 激活，CPI $2.94（含竞品素材）
- 菲律宾: 639 激活，CPI $0.22（含竞品素材）
- 两国 CTR 相近: 2.2%-2.4%，CVR 约 24%

### 素材方向表现

| 方向 | 子类 | CPI | CTR | CVR | 评价 |
|------|------|-----|-----|-----|------|
| 宝可梦题材 | 核心玩法（剧情抓宠→战斗→BOSS） | **$3.99** | 2.35% | 22% | ⭐ 最佳自有素材 |

| 模拟经营 | 砍树 | $0.49 | - | - | 衰退期推测 |

### 素材创意关键发现

1. **最吸量模式**: **剧情获取宠物开头 → 宠物战斗&升级 → 打BOSS**
2. **获取宠物方式的对比**（菲律宾）:
   - 精灵球获取 vs 宠物遭虐杀-逃跑-被收养 → 两者 CPI 相当（$0.1左右）
   - 建议测试: 宠物诱捕/猎杀（邪恶系）、流浪宠物收养（治愈系）
3. **战斗方式的对比**（菲律宾）:
   - 幻兽帕鲁战斗 CTR 3.69% > 卡牌对战 CTR 2.33%（高 58%）
   - 但卡牌对战 + 获取宠物剧情 → CPI 比帕鲁战斗低 60%（剧情比战斗形式更关键）
4. **前3秒优化**: CTR 高的素材，3秒播放率都高；优化前 3 秒 = 优化 CTR
5. **图片 vs 视频**: 图片直接表现美术画风，美国 CPI $5.35（偏高），菲律宾 $0.27

### 用户属性（1月吸量测试）
- **美国**: 35-54 岁占 78%，其中 35-44 最多（35%）；男女比 7:3
- **菲律宾**: 18-44 岁占 87%，其中 25-34 最多（36%）；男女比接近 9:1
- **素材×年龄**: 【数字门】在两个区域都吸引更高龄用户（美国 45-64 占 62%）
- **素材×性别**: 美国【抽卡展示】【核心玩法】【砍树】女性占比 50-60%

## 二、画风测试（1-2月）

### 测试设置
- **渠道**: Facebook
- **预算**: $470.61（实际花费）
- **受众**: 美国，手游 ∩ 策略游戏，男女不限，18+
- **素材**: 3 只宠物 + 1 张合照 × 2 种画风（新/旧）= 8 张图片
- **规则**: 每广告达 2000 展示自动关闭；仅图片为变量
- **落地页**: https://umi.game/palkieWild/landing

### 核心结论

| 结论 | 详情 |
|------|------|
| 🎨 **新画风全面优于旧画风** | 同等展示下量级多 35%，CPI 低 30%（$2.69 vs ~$3.84），各维度均一致 |
| 👨 男性仅占 30% | 偏离目标 7:3 或 6:4，需设计更吸引男性的宠物 |
| 🐱 宠物吸量排序(女) | 吸水喵 > 合照 > 土波波 >= 幽飘 |
| 🐶 宠物吸量排序(男) | 幽飘 > 土波波 > 吸水喵 > 合照 |

### 整体数据
- 总花费: $470.61，CPI $3.00，CTR 3.25%，CVR 25%，CPM $25

### 性别维度
- 男性 CPI $4-$5（CTR 仅 2%），女性 CPI $2-$3（CTR 4%，为男性 2x）
- 除土波波和幽飘男性占比 30-60% 外，其他素材男性比例均 <20%

### 年龄维度
- 新画风年龄跨度更大: 25-54 岁占 70%
- 旧画风集中在 25-44 岁占 70%
- 旧画风对 65+ 用户基本无吸引力
- 同样素材不同画风 → 旧画风用户更年轻（比如土波波旧画风 25-44，新画风 45-64）

## 三、4月留存测试（4/2 - 4/4）

### 测试设置
- **预算**: $5,000 以内，计划 ~$4,700
- **量级**: 美国 800，菲律宾 1,200
- **周期**: 3 天（4/2 10:00 PH 开启 → 同天 21:00 US 开启）
- **出价**: Install + AEO（首次开启 AEO 测试）
- **行业标准**: 美国 CPI $3.5-$5，菲律宾 CPI ~$0.2

### 核心结论

| 指标 | 数值 | 评价 |
|------|------|------|
| 平均次留 | 25.64% | 🇺🇸 30.87%、🇵🇭 23.31%；低于行业标准（美 36.3% / 菲 36.8%），但当前版本较初级，表现良好 |
| 美国 install CPI | **$3.91** | 在行业线 $3.5-$5 内 ✅ |
| 菲律宾 install CPI | **$0.35** | 高于行业线 $0.2 ❌ |
| 整体转化率 | 21.08% | 偏低，需优化 |
| AEO CPI | $5.85(美) / $0.97(菲) | 美国刚好达到预期 |

### 优势
1. 美国次留 30.87%，在当前初级版本下表现良好
2. 美国 Install CPI $3.91 在行业标准线内
3. 验证最佳素材方向: **抓宠+升级+战斗**（美国/菲律宾留存&吸量双优）
4. 菲律宾 Install 用户: **模拟经营**和**建筑升级**类素材留存最优

### 待优化
1. **转化率**: 整体 21.08% 偏低；优化方向：包体（826M过大）、商店图、受众
2. **菲律宾成本**: Install $0.35 + AEO $0.97 均偏高
3. **AEO 学习**: AEO 事件量级过少导致学习未完成，数据波动大

### 出价类型对比

#### 美国
| 出价类型 | 次留 | CPI | 评价 |
|----------|------|-----|------|
| Install | 28.9% | $3.91 | 基准 |
| AEO-tur7（~6分钟） | **39.69%** | $5.58 | ⭐ 次留比 Install 高 11pp |
| AEO-强制引导（~4分钟） | 13.33% | - | ❌ 已关停，CPM 高 26% |

#### 菲律宾
| 出价类型 | 次留 | CPI | 评价 |
|----------|------|-----|------|
| Install | 逐步下降 | $0.45 | 学习期波动大 |
| AEO | 高 5-15pp | Install 的 2-2.3x | 价格无优势，学习未完成 |

### 素材维度详细

#### 美国 — Install
- **留存最佳**（次留 >35%）: V-核心玩法、V-高效抓宠、P-灾后重建（均为抓宠+战斗）
- **留存最差**（次留 ~15%）: P-幻想宠物3、帕基世界冒险（像素风与游戏风格不一致）
- **吸量最佳**（CPI $3.3-$3.5）: V-场景展示、V-核心玩法、V-抓宠战斗

#### 美国 — AEO（次留整体 36.99%）
- 激活>20 的素材: 抓宠战斗、P-海啸，次留均 >38%
- AEO 点击率比 Install 低 30%（用户对素材要求更高）

#### 菲律宾 — Install
- **留存最佳**: 升级对比、场景升级展示、天灾重建（模拟经营+建造）、抓宠战斗（战斗爽感）
- **吸量最佳 CTR**: 场景升级展示、帕基世界冒险（无开头剧情，纯AI制作→推测开头剧情和AI+UE画风不统一影响吸引力）
- **海啸避难**: CTR 和 CPI 最优，但次留最差（天灾效果与预期不符→用户流失）

#### 菲律宾 — AEO
- **留存最佳**: 高效抓捕、抓宠战斗、幻想宠物（宝可梦题材+抓捕玩法匹配度高）
- **吸量最佳**: 高效抓捕（抓捕→复制的简单逻辑更符合菲律宾用户喜好）
- 建造玩法素材（升级对比、场景升级展示）在 AEO 中表现一般

## 五、跨测试总结

### 已验证的核心结论

1. **吸量**: 
   - 最佳素材模式: **剧情获取宠物 → 战斗&升级 → 打BOSS**（1月+4月一致验证）
   - 新画风 > 旧画风（画风测试验证）
   - 副玩法【数字门】美国吸量好、【搜索射击】菲律宾吸量好

2. **留存**:
   - 美国次留 30.87%（初级版本下可接受）
   - 抓宠+战斗类素材留存最高（Install 35%+）
   - AEO-tur7（~6分钟点位）次留比 Install 高 11pp

3. **核心问题**:
   - 转化率持续偏低（21-24%），需优化包体、商店图、受众
   - 菲律宾成本持续高于行业标准
   - 美术细节（场景/模型/动作/特效）与竞品差距大
   - 男性用户占比偏低（尤其画风测试仅 30%），需设计更吸引男性的宠物

4. **竞品标杆**:
   - 莉莉丝 Palmon Survival: 美国 CPI $0.84、CTR 4.23%、CVR 43%（1月数据）
   - 竞品的素材创意和制作细节值得深入研究
