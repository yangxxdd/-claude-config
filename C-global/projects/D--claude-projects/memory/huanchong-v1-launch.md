## 研运协作问题

| 问题 | 优化方案 |
|------|---------|
| 目标认知模糊 | 规范测试/上线目标标准 |
| 版本内容不明确（漏配FB配置） | 明确内容&需求，形成共享文档 |
| 排期不明确 | 确定落地时间+责任人，共享文档 |
| 信息同步不到位 | 明确责任人+企微群+每周周会 |

## 本地化 & LQA

- 审校 4.8w+ 字，临时文本 2 则 460+ 字
- 非语言 bug 56 条以上，语言类优化近 5k+ 字
- 核心问题:
  - 文本提取不完整
  - 表述不一致
  - 变量缺备注（占 Query 10%）
  - 缺跑测清单
  - LQA 验收流程不完善
- SOP 优化: 正式通知后提取、梳理表述一致性、Context 表备注、跑测清单、Bug 表进度透明化

## 后续计划

- 运营团队尽早介入版本内容制作
- 前置运营反馈（参与需求预审）

- 信息认知一致、分工明确、文档规范
