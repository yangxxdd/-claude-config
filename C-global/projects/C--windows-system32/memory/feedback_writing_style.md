When writing work documents (reports, analysis for superiors), aim for the middle ground:
- Not AI-sounding: avoid formulaic patterns, jargon chains connected by `+`, buzzwords like "核心爽点", "操控维度", "初步评估"
- Not overly colloquial: avoid chat-style language, keep it professional enough for a formal document
- The right tone: like an experienced professional writing a work report — direct, clear, no fluff, but still polished

**Why:** User found my first version too AI-like, then my rewrite went too far in the other direction (too casual/口语化, like chat messages). Neither extreme works for a work document submitted to a superior.

**How to apply:** When writing Chinese work documents, aim for concise, professional but natural language. Think "competent colleague writing a memo" not "chatbot" and not "friend texting."
